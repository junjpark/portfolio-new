# Selected work images

Put project images here, then list them in the `WORK` array in `index.html`:

```js
{ src: 'work/my-project.jpg', w: 1600, h: 1200, kicker: 'Client or year', title: 'Project name', href: 'https://…' }
```

- `w` / `h`: the image's pixel size (keeps the layout from jumping while it loads).
- `kicker`, `title`: optional; shown over the image on hover.
- `href`: optional; makes the tile a link.

Images of any shape work. The board lays them out in columns like a pinboard.
