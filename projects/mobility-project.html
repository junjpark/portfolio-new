Mobility Project

A map-based tool for exploring how people move around campus, built for a WashU psychology research team.

Timeline
May 2025 – October 2025
Stack
  • React
  • Mapbox GL
  • Python
  • Flask
  • GeoPandas
  • Parquet
  • OSRM

Overview

A web app for exploring how people move around a campus. It takes location traces (GPS tracks from the Dartmouth StudentLife dataset and WashU WiFi connection logs) and turns them into trips you can filter, replay and route on an interactive map.

We built it for a psychology research team at WashU.

What I built

  • Data pipeline. A Python ETL with one processor per data source, all mapped onto a single schema and saved as GeoParquet, plus a converter for Excel and CSV uploads.
  • Spatial API. A Flask API for uploading files, querying trips inside a map area or by date, and exporting the filtered data back to Parquet, with pagination and caching.
  • Trips on real roads. Raw GPS points are snapped onto streets with OSRM map-matching. An offline job matches routes concurrently in batches and caches them, so the map doesn’t wait on the routing service.
  • Map interface. A React and Mapbox GL front end that replays trips on a timeline with the camera following along, shows how often each route is used, and matches stops to nearby points of interest.

Outcome

The biggest lesson was how to work with messy, unclear data. The sources came in different formats (GPS tracks from one study, WiFi connection logs from another, and spreadsheets), and raw GPS points drift off the streets. Most of the work was turning all of that into one consistent schema the research team could explore on a map.
